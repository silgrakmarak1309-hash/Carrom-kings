# CARROM KING 👑

**CARROM KING** is a modern, responsive, high-performance Carrom board web game built with React, TypeScript, Canvas 2D, and Tailwind CSS. It features realistic 2D physics, accurate coin/goti collision detection, customizable striker controls, AI opponents, puzzle trick shots, pass-and-play 2 player mode, sound effects, player profiles, and responsive touch controls for mobile, tablet, and desktop.

---

## ✨ Key Features

- **🎮 4 Game Modes**:
  - **VS Computer**: Challenge an intelligent AI opponent with multiple difficulty levels.
  - **2 Players (Pass & Play)**: Compete locally with a friend on the same screen.
  - **Puzzle Mode**: Solves 20 tactical trick shot levels with limited shot counts.
  - **Free Practice Mode**: Warm up shots with unlimited retries and free placement.
- **👑 Golden Crown Esports UI**: Modern dark esports theme with gold accents, player profile avatars, sound controls, and polished HUD modals.
- **⚡ Physics Engine**: Accurate 2D impulse physics, friction, restitution (bounciness), board border bouncing, and pocket detection.
- **🎯 Precision Striker Control**: Symmetrical shooting power slider & drag aiming with dual guide lines for shot prediction.
- **📱 Touch & Mobile Optimized**: Fully responsive layout optimized for Android, iOS, tablets, and desktop browsers.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js (v18 or higher) and `npm` or `bun` installed on your system.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/silgrakmarak1309-hash/Carrom-king-.git
   cd Carrom-king-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:3000` to play CARROM KING!

---

## 🛠️ Building for Production

To create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
